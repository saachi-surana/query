# Query

Live Q&A platform with AI-powered question clustering. Submit questions, upvote, and watch AI organize them into topics in real-time.

## Features

### Core Q&A
- Create sessions with 6-character join codes
- Submit questions (500-char limit, anonymous toggle)
- Upvote/un-upvote questions
- Threaded replies (host + attendee)
- Real-time updates via Supabase subscriptions

### AI Intelligence
- Real-time AI clustering — questions automatically grouped into topics
- AI-generated summary questions per cluster ("Q" AI assistant)
- AI-suggested answers based on session context
- Inline-editable AI summaries with "Generated by Q" / "Edited" badges
- FAQ library that carries across recurring sessions

### Host Tools
- Question moderation (approve/reject before display)
- Multi-moderator support with cluster claiming
- "Discussing now" cluster highlighting
- Session analytics dashboard
- Post-session follow-up answers
- Recurring sessions
- Re-cluster button for manual AI re-organization

### Interactive Features
- Multiple choice polls (single + multi-select)
- Word clouds
- QR codes for easy joining (SVG + PNG download)

### Customization
- Custom host branding (logo + accent color)
- Dashboard theme picker (Orange, Purple, Blue)
- Presentation mode for projection

### Export & Reporting
- CSV export
- PDF export
- Post-session report page

## Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Database**: Supabase (PostgreSQL + Real-time subscriptions)
- **Auth**: Supabase Auth (email/password)
- **Storage**: Supabase Storage (logos)
- **AI**: Google Gemini 2.0 Flash Lite (primary), configurable via GEMINI_MODEL env var
- **Libraries**: qrcode.react, jsPDF

## Getting Started

### Prerequisites
- Node.js 18+
- Supabase project (with tables set up from `supabase-schema.sql`)
- Gemini API key (free tier available)

### Setup

```bash
git clone https://github.com/saachi-surana/query.git
cd query
npm install
```

Create `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
GEMINI_API_KEY=your-gemini-key
# Optional:
GEMINI_MODEL=gemini-2.0-flash-lite  # default
ANTHROPIC_API_KEY=your-anthropic-key  # fallback provider
```

Run the database migrations:
```bash
# For fresh setup: run supabase-schema.sql
# For existing DB: run supabase-migrations.sql
```

Start the dev server:
```bash
npm run dev
```

## Routes

| Route | Description |
|-------|-------------|
| `/` | Home — join or host a session |
| `/demo` | Interactive demo — no login or session required |
| `/create` | Create a new session |
| `/join/[code]` | Attendee view (Ask, All, Topics, Mine tabs) |
| `/session/[code]` | Host/moderator dashboard |
| `/present/[code]` | Presentation view (projectable) |
| `/report/[code]` | Post-session report |
| `/analytics` | Cross-session analytics dashboard |
| `/settings` | Profile, defaults, appearance |
| `/login` | Host login |
| `/signup` | Host signup |

## Architecture

- **No auth for attendees** — sessions are URL-based with 6-char join codes
- **All real-time** via Supabase `postgres_changes` subscriptions
- **AI clustering** via `/api/cluster` → `lib/clustering.ts` → Gemini API
- **Theme system** using CSS custom properties (`--theme-primary`, etc.)
- **Brand override** component applies host branding as CSS variables
